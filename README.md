# ACE Admin Portal

Official admin portal repository for the ACE (Ace Community Express) Program by Brototype.

## Overview

This repository hosts the admin portal platform, providing administrative tools, candidate inquiry management, and integrations for the ACE Community.

## Project Structure

```text
ace-admin-portal/
├── backend/          # Node.js Express & MongoDB backend service
├── frontend/         # React, Vite, TypeScript & Tailwind CSS Admin Dashboard
└── README.md
```
